# Multi-Modal Visual Question Answering

> Status: In Development

## Overview
A deep learning system that answers natural language questions about images by combining computer vision and natural language processing through multi-modal transformers.

## Tech Stack
- Python 3.10+
- PyTorch
- Hugging Face Transformers (CLIP, BLIP)
- Gradio (Interactive demo)
- Weights & Biases (Experiment tracking)

## Project Goals
- [ ] Data pipeline for VQA dataset
- [ ] Baseline vision-language models
- [ ] Fine-tuning multi-modal transformers
- [ ] Attention visualization
- [ ] Interactive demo application

## Dataset
VQA v2 or GQA (Visual Question Answering datasets)

More details coming soon as the project develops.
